# Вёрстка сервиса YouTalk

Выполнил: Ярцев Владислав

Учебный проект по вёрстке: две страницы онлайн-сервиса психологической помощи YouTalk - главная (блог) и страница статьи. Проект собран на чистом HTML и CSS без JavaScript и фреймворков.

## Страницы

| Страница | Файл | Стили |
|----------|------|-------|
| Блог | `pages/index.html` | `bundles/index.css` |
| Статья | `pages/article.html` | `bundles/article.css` |

## Запуск

Проект статический: достаточно открыть HTML-файл через локальный сервер, чтобы корректно подтягивались пути к стилям и изображениям.

```bash
# Пример с npx (из корня проекта)
npx serve .
```

После запуска откройте в браузере:
- `http://localhost:3000/pages/index.html` - блог
- `http://localhost:3000/pages/article.html` - статья

## Структура проекта

```
frontend-basics/
├── pages/           # HTML-страницы
├── bundles/         # Сборки CSS для каждой страницы
├── blocks/          # Блоки по методологии БЭМ
├── assets/images/   # Изображения
├── tokens.css       # CSS-переменные (цвета, токены)
├── main.css         # Общие стили
└── reset.css        # Сброс браузерных отступов
```

Каждый блок лежит в отдельной папке. У блока есть основной файл (`block.css`), элементы (`__element`) и модификаторы (`_modifier`). Например:

```
blocks/exercise/
├── exercise.css
├── __header/exercise__header.css
├── __text/exercise__text.css
└── _color/
    ├── exercise_color_beige.css
    ├── exercise_color_orange.css
    └── exercise_color_blue.css
```

## Технологии

## Преимущества проекта

**1. Понятная структура кода**

Разметка разбита на независимые блоки: шапка, подвал, карточка, кнопка, цитата, упражнение и т.д. Каждый блок отвечает за одну часть интерфейса. Это упрощает поиск нужного стиля и правку отдельных элементов без риска «сломать» соседние.

**2. Переиспользование компонентов**

Общие части - header, footer, button, container, breadcrumbs - используются на обеих страницах. Новая страница собирается из уже готовых блоков, а не с нуля.

**3. Раздельные CSS-бандлы**

Для блога и статьи подключены разные файлы стилей (`index.css` и `article.css`). На страницу попадают только нужные блоки, без лишнего кода.

**4. Адаптивная вёрстка**

Макет корректно отображается на экранах разной ширины. Горизонтальные блоки (колонка статьи и промо-блоки, блоки с изображением и текстом) на узких экранах выстраиваются в колонку. Шапка на мобильных устройствах упрощается: навигация скрывается, появляется кнопка меню.

**5. Единая дизайн-система**

Цвета, отступы и типографика заданы согласованно. Кнопки имеют варианты (`primary`, `inverse`), списки - модификаторы (точки, подчёркивание, размер), блоки упражнений - цветовые темы. Интерфейс выглядит цельно на всех страницах.

**6. Чистый CSS без зависимостей**

Проект не требует установки npm-пакетов, сборщиков или фреймворков. Достаточно браузера и локального сервера. Это удобно для учебных задач и для понимания основ вёрстки «изнутри».

**7. Семантическая разметка**

Используются теги `header`, `main`, `footer`, `section`, заголовки разных уровней. Страница остаётся читаемой и для браузера, и для вспомогательных технологий.

## Основные блоки страницы статьи

На странице статьи помимо общих компонентов используются:

- `article-content` - содержание статьи
- `cite` - цитаты (с модификаторами `default` и `anonym`)
- `exercise` - блоки с упражнениями (бежевый, оранжевый, синий)
- `image-aside` - изображение с текстом в ряд
- `image-pair` - два изображения рядом
- `image-with-caption` - изображение с подписью
- `links-list` - список ссылок через точку
- `article-cta` - призыв к действию внизу страницы
